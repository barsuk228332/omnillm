# Безопасность

## Ключи и секреты

- API-ключ хранится только в `context.secrets` VS Code и никогда не пишется
  в `settings.json`, исходники или логи.
- Расширение не отправляет ключ никуда, кроме выбранного вами `baseUrl`.
- При смене провайдера ключ нужно задать заново.

## Сообщения об уязвимостях

Не открывай публичный issue. Используй GitHub Security Advisories:

<https://github.com/barsuk228332/omnillm/security/advisories/new>
